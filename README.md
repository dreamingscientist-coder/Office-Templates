# Office Templates

Free, ready-to-use Excel tools and reference sheets for engineering and office work.
All files are in the [`Excel`](./Excel) folder.

## Files

| File | What it does |
|---|---|
| `Alloy_Chemical_Composition.xlsx` | Reference table of alloy chemical compositions |
| `BOM VM.xlsm` | Bill of materials (BOM) tool (uses macros) |
| `Cutting speed Tool.xlsx` | Calculates cutting speed for machining tools |
| `Excel_Functions_EN_FR.pdf` | Excel function names, English to French |
| `ISO 13920.xlsx` | General tolerances for welded structures (ISO 13920) |
| `ISO2768.xlsx` | General tolerances for machined parts (ISO 2768) |
| `SPLIT_COMBINE_Tool.xlsm` | Splits and combines Excel files (uses macros) |
| `Shaft_Hole Standard Tolerance.xlsx` | Standard fits and tolerances for shafts and holes |
| `Split file base on column.xlsm` | Splits a file into several files based on a column (uses macros) |

## How to use

1. Click the file you want, then click **Download raw file** (the download icon).
2. Open it in Excel.
3. For `.xlsm` files, click **Enable Content** to allow the macros. Only enable macros from sources you trust.
